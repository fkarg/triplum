# Standard QA, KGQA and entity-linking benchmarks

Snapshot 2026-09-17. A Codex (GPT-6-astra) research pass, run read-only against this repository
with every listed data URL exercised by an anonymous HTTP request; the tables below are its
report, kept verbatim apart from this header. It fills the two families the
[benchmark catalogue](benchmarks-catalogue.md) could not cover (KGQA over an existing KG, entity
linking) and lists the standard QA sets that catalogue skipped. Nine licence and gating claims
were re-checked by hand against the Hugging Face API on 2026-09-17 and matched. The first two
adoption tiers at the end are registered except KQA Pro and the non-QA sets (OpenEA, BEIR); see the [catalogue](benchmarks-catalogue.md#4b-registered-on-2026-09-17)
for what each registration decided.

Row counts are configurations, not independent datasets. "Unverified" is stated wherever a size,
count or licence could not be established from a primary source.

## How to read the catalogue

- **Scope:** optional, auto-fetchable registry candidates, not a default benchmark suite. A configuration is sometimes its own row; row counts do not equal independent datasets. Corpora are dependencies, not scored QA datasets.
- **Verification:** the listed data URLs received real anonymous HTTP HEAD or ranged/full GET requests. Successful public files returned 200/206. Of 613 unique listed data URLs, 612 returned successful HTTP responses; the unavailable Freebase raw dump is explicitly retained as an HTTP 403 exception. Restricted TAC/BEIR corpora have no invented download URL. No login, access token or private credentials were used. A transient Hugging Face 429 limit cleared on retry; it was not a gate.
- **Sizes:** decimal MB (`1 MB = 1,000,000 bytes`), wire/compressed size for archives, stored size for parquet. Per-file bytes are in `lane-a.json`; table totals sum listed files, including alternatives where explicitly noted. These are not RAM/index sizes. A null byte size means **unverified**, not zero. Large sharded rows show representative exact URLs; the JSON lists every selected shard.
- **LFS/gating:** `lfs=true` records HF metadata indicating LFS/Xet-backed content. Use `/resolve/main/`, not `/raw/main/` or a Git LFS pointer. Anonymous redirects to public object storage work without a token. A Drive `resourcekey` is part of the public share URL, not a login credential. `gated=null` means gate status unverified; HTTP 403 alone does not prove token access would work.
- **Schema/counts:** record fields refer to the selected package, not a hypothetical unified adapter. HF parquet fields/counts are taken from its declared schema; original JSON/TSV/ZIP examples were inspected where stated. Nested wrappers and TSV/positional formats are named explicitly. Counts marked measured come from files; reported/card counts were not all independently enumerated. **Unverified** gaps remain visible.
- **Licences:** exact declarations and their scope are reported, including conflicts. “None declared” means none found in the inspected primary/card/archive sources, not public domain. A code/repository licence or third-party mirror label does not establish ownership of all embedded Wikipedia/news/book content. Public availability and permission to redistribute are different facts.
- **Protocol:** answer-string datasets without document IDs cannot directly measure gold retrieval recall; use answer-bearing retrieval as a named proxy. Supplied gold context, supplied entity spans, candidate-restricted linking and full-corpus retrieval are different tasks. Keep hidden-test handling, snapshot IDs and split names explicit.

**Coverage:** 114 entries across 7 families; 613 file references (alternatives/configuration overlaps included).

## Recommended tiers

These are recommendations for **optional registration**, with fetch-on-request and no automatic benchmark execution. They separate download cost from rights and corpus dependencies.

1. **Register first: small, self-contained releases with clear data declarations.** EntityQuestions (4.83 MB, MIT; question-only initially), Bamboogle (~0.008 MB, MIT; retain alternate answers from the official sheet when normalizing), FreshQA (~0.20 MB, repository Apache-2.0; freeze the dated sheet), QuALITY v1.0.1 (18.02 MB, CC-BY-4.0 plus article licence field), QASPER (14.70 MB, CC-BY-4.0), and MetaQA vanilla with its 5.22 MB movie KG (about 67.68 MB total questions+KG, CC-BY-3.0). These offer cheap QA, long-context, abstention and actual KG traversal coverage. ARC is another tiny science-QA baseline. EntityQuestions/Bamboogle/FreshQA can be registered cheaply without making a claim that their retrieval corpus is included.
2. **Add small releases with explicit ShareAlike obligations.** SQuAD 1.1/2.0, BoolQ, NQ-Open annotations, AmbigQA and full MuSiQue dev are useful next. ShareAlike is a real condition, so this is not “MIT-style permissive.” KQA Pro (~181.77 MB including its finite KB, author CC-BY-SA-4.0) is the strongest convenient self-contained complex KGQA addition. OpenEA v2.0 (~248.80 MB, Figshare CC-BY-4.0) gives a self-contained entity-alignment task. WikiDiverse’s 0.69 MB annotations are cheap, but multimodal evaluation still needs images and candidate descriptions; ZESHEL needs its 320.94 MB dictionary/context archive and has an unspecified CC-BY-SA version in the primary README.
3. **Register shared-corpus dependencies once and pin the mapping.** DPR psgs_w100 (4.69 GB) supports classic open retrieval but its corpus-specific licence must be clarified separately from DPR’s CC-BY-NC repository declaration. KILT Wikipedia (37.32 GB) supports all 11 KILT task configurations with provenance IDs. Hotpot abstracts (1.55 GB), FEVER wiki (1.71 GB), HoVer SQLite (2.16 GB), IIRC contexts (0.39 GB), and QAMPARI chunks (6.42 GB) are distinct snapshots, not interchangeable caches. A corpus registry should preserve original IDs and map any new chunks back to them. WebQSP, CWQ, GrailQA and FreebaseQA need the matching Freebase setup for query execution; LC-QuAD/QALD need their DBpedia/Wikidata versions. Question-only closed-book or stored-denotation scoring can be cheap even when KG execution is expensive.
4. **Keep large downloads explicit.** Full NQ selected parquet is 56.84 GB. TriviaQA selected parquet expands repeated evidence (rc ~9.00 GB; unfiltered ~16.70 GB), whereas original tarballs are 2.67 GB for RC plus 0.63 GB for unfiltered annotations; the unfiltered original uses evidence from RC, so raw unfiltered-with-evidence needs both (~3.30 GB). Fetch one packaging route. MS MARCO QA v2.1 is ~2.11 GB, passage-ranking collection ~1.04 GB plus queries/qrels. QAMPARI retrieved-context expansion is ~9.19 GB. KILT, the ~56.32 GB processed Freebase database and ~57.05 GB QALD-10 Wikidata require substantial unpacked/index space. Wikidata5M is ~1.57 GB across alternative graph splits, aliases and text; use it for its own graph task, not as a substitute for a benchmark’s complete KG.
5. **Hold registration behind explicit rights/availability metadata.** TAC-KBP and the four restricted BEIR corpora (BioASQ, Signal-1M, TREC-NEWS, Robust04) need provider-specific access; they cannot be presented as anonymous auto-fetch datasets. MS MARCO is research/non-commercial. AIDA/ACE and the small news EL mirrors are technically public but have source-rights caveats. PopQA, LC-QuAD2, TimeQuestions, ZELDA, and other “none declared” releases need clarification before being labelled permissive. IIRC has a concrete conflicting licence file. The raw Freebase URL currently fails; retain it as unavailable, with the processed author DB documented separately.

For BEIR, start with the small complete corpora **SciFact, ArguAna and NFCorpus**, but retain the actual per-source declarations: SciFact annotations are CC-BY-4.0 and abstracts ODC-By-1.0; BEIR HF cards broadly say CC-BY-SA-4.0 and are not blanket evidence that every upstream corpus was relicensed. Do not report a single “BEIR licence.” CQADupStack’s official 5.34 GB ZIP repeats whole community query maps inside individual query metadata (verified on actual records). Only `text` should enter the query prompt. A lighter conversion needs corpus/query/qrels parity verification before adoption; see its row.

Before implementing adapters, freeze URLs to release/commit revisions where possible and store checksums, selected configuration, original split, record unit, gold visibility, corpus revision and licence scope. Do not sum alternate releases (TriviaQA archives/parquet, Hotpot configs, MuSiQue ans/full, SimpleQuestions mapped/answerable, Wikidata5M inductive/transductive) as new independent examples. No data loader, benchmark run, repository edit or licence clarification was performed by this research task.
