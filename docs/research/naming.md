# Naming

Decision 2026-09-16: **triplum**.

Latin "triple" (subject, predicate, object is the atom of everything here); also the third,
independent voice in medieval polyphony, which is a fair picture of modules that work alone and in
composition. Preference was for Latin-ish or punny names.

## Collision sweep

Method: PyPI (`https://pypi.org/pypi/<name>/json`), crates.io (`/api/v1/crates/<name>`), GitHub
repo search, web search for products/protocols. Every bare GitHub org handle in the list was already
taken, so the repo lives under a personal account regardless.

Free on both registries with only non-software collisions: **triplum** (a triple-sec liqueur, a
musicology term), retiarius (two dormant companies), gordius (MIDI hardware, an aerospace firm),
nexilis (an insurtech branding on the same meaning), ligamen (a French HR product), araneum (small
IT consultancies), ligatura, textrinum, nodulus.

Dropped for active same-space or household-name collisions: graphium (datamol GNN library),
nodus (InfraNodus, NODUSmap KG tools), ragu (RAGU modular GraphRAG framework, Sept 2026), conexus
(semantic-search package updated the same day), catena (Catena-X KG standard), ragtime (a RAG-eval
framework), ragtag, reticulum (7k-star networking stack), trivium (eSTREAM cipher, TriviumDB),
arachne (ships an RDF library), plexus (Codehaus/Maven), tela, vinculum, nexum, retis, copula,
textus, filum, contextus, tabularium, officina, textrix.

Runner-up was araneum ("spider's web"); retiarius was the punny option.
