# Learn triplum

Start with a document, then see how to supply and load records, turn them into store frames, and
read them with a viewer. Each page introduces one idea with a small example.

1. [Documents](documents.md): represent text and its source.
2. [Sources](sources.md): make records available to an experiment.
3. [Loading batches](loading.md): read source records in groups.
4. [Corpus frames](frames.md): convert records for the store.
5. [Viewers](viewers.md): choose whose data a store read can see.
6. [Reading from a store](store.md): write and retrieve visible text.
7. [Run a benchmark](benchmark.md): compare a baseline on a small fixture.

For a complete benchmark, continue with [datasets](../datasets.md) and
[benchmark runs](../flow.md). For signatures and every available method, use the
[API reference](../api/index.md).
